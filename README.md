# Мини Игры — тетрадь в клеточку

Telegram Mini App с игрой **2048**. Минималистичный интерфейс: тетрадь в клеточку, элементы от руки синей ручкой, без дополнительных фоновых панелей.

## Запуск

Откройте `index.html` в браузере. Для Telegram опубликуйте `index.html`, `style.css` и `app.js` на HTTPS-хостинге (например, GitHub Pages).

## Подключение Telegram

1. Создайте бота через @BotFather.
2. Опубликуйте сайт по HTTPS.
3. Настройте кнопку меню через `/setmenubutton`, указав URL опубликованного сайта.

## Возможности

- 2048: свайпы, стрелки клавиатуры, экранные кнопки.
- Счёт, рекорд и сохранение текущей игры в localStorage.
- Победа, продолжение после 2048, проигрыш и перезапуск.
- Необязательный звук и тактильная отдача Telegram.

Прогресс хранится локально и пока не синхронизируется между устройствами.
